# BioSynth - Landing Page

Una landing page moderna y atractiva para BioSynth, un biofertilizante natural modular desarrollado con enfoque sostenible.

## 🌱 Sobre BioSynth

BioSynth es un biofertilizante líquido natural desarrollado como alternativa efectiva, sostenible y accesible frente al uso excesivo de fertilizantes químicos. Su fórmula modular busca nutrir la planta, protegerla de plagas y regenerar los suelos agotados, todo en una sola aplicación.

### Características Principales

- **100% Natural**: Ingredientes orgánicos y biodegradables
- **Modular**: Sistema adaptable a diferentes cultivos
- **Sostenible**: Cuida el medio ambiente y la salud
- **Eficiente**: Una sola aplicación completa
